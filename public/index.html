Quick start: try it in one click

The app has three tools. Each card below has a button that runs a ready-made example, so you can see what it does before typing anything.

1

Contacts

Save a Solana address with a name. We tell you if it's a normal wallet or a program-controlled PDA, and can work out its token account.

2

Derive a PDA

Give a program's address and a few seed words. Get back the one address those inputs always produce (plus its bump number).

3

Verify a signature

Prove someone owns an address. They sign a message with their wallet and we check the signature matches.

    What is a PDA?

    A Program Derived Address is an address a Solana program can compute from its own address plus some “seed” words. The same inputs always give the same result, so anyone can recompute it.

    1. 1

      Enter the Program ID (already filled in).

    2. 2

      Type your seeds, one per box. Add more with “+ Add seed”.

    3. 3

      Press Derive PDA. Your answer appears on the right.

    Inputs

    The address of the on-chain program. The default is the Associated Token Account program.

    Plain text words. Order matters: a, b and b, a give different results.

    Result

    Your PDA and bump number will appear here after you press “Derive PDA”.

    What does this check?

    Only the owner of an address's private key can produce a valid signature for a message. If the signature matches, you know the person really controls that address. Nothing is sent to the blockchain.

    1. 1

      Fill the form. Use an example, sign with your wallet, or paste your own address, message and signature.

    2. 2

      Press Verify signature.

    3. 3

      Read the result on the right: a green valid or a red invalid.

    Inputs

    Must match the signed text exactly, including spaces.

    Result

    The result appears here after you press “Verify signature”.

    New to Solana? Words explained

    Plain-English meanings for the terms used in this app.

    Address
    A long code that identifies an account on Solana, a bit like a bank account number. Also called a public key.
    Wallet
    A normal account owned by a person, controlled by a secret private key (Phantom and Solflare create these).
    PDA
    Program Derived Address. An account with no private key. Only the program that derived it can control it.
    Seed
    A word or value that, together with a program ID, decides which PDA you get.
    Bump
    A small number (usually 255 or just below) the algorithm adds to make sure the PDA is a valid program-controlled address.
    Mint
    The address that defines a token, such as USDC. Every token has exactly one mint.
    ATA
    Associated Token Account. The standard place where a wallet keeps its balance of one specific token.
    Signature
    Proof, made with a private key, that the owner approved a message. Anyone can check it without knowing the key.
    Base58
    The letters and numbers format Solana uses for addresses and signatures. It skips look-alike characters (0, O, I, l).

    For developers. Base URL: · JSON in, JSON out.

    GET/api/contacts?type=&q=List & search contacts
    POST/api/contactsCreate · {name, address}
    GET/api/contacts/:idFetch one contact

    DELETE/api/contacts/:idRemove a contact
