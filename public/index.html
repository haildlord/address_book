    API reference

    Base URL: · JSON in, JSON out.

    GET/api/contacts?type=&q=List & search contacts
    POST/api/contactsCreate · {name, address}
    GET/api/contacts/:idFetch one contact
    DELETE/api/contacts/:idRemove a contact
    PATCH/api/contacts/:idUpdate · {name?, address?}
    POST/api/contacts/:id/derive-ata{mintAddress, tokenProgram?}
    POST/api/derive-pda{programId, seeds[]}
    POST/api/verify-ownership{address, message, signature}
